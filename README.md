# TON 618 — Punjab Simulation 🌌

A real-time, first-person 3D-style simulation built with **Python and Pygame**, set in a fictionalized Punjab environment where one of the most massive known black holes, **TON 618**, approaches Earth.

Explore the streets, enter buildings, observe pedestrians and vehicles, and watch as the sky transforms into an increasingly terrifying astronomical event.

> **The universe is not ending quietly.**

## 🌍 Overview

TON 618 — Punjab Simulation is an experimental interactive environment featuring a simulated town, dynamic NPC behavior, vehicles, buildings, and a gradually approaching cosmic threat.

The experience focuses on visual atmosphere, perspective rendering, environmental interaction, and the reactions of the simulated population.

## ⚠️ HEADS UP BEFORE PLAYING

A few things you should probably know before jumping in:

- **The pedestrians:** Yes, they look like sticks. No, they are not particularly photogenic. They're doing their best. 😭
- **Graphics:** This project uses custom Pygame rendering, so don't expect Unreal Engine-level visuals.
- **Physics:** Some movement, collisions, and animations may look a little questionable.
- **Performance:** The simulation can get demanding depending on your hardware and graphics settings.
- **Scientific accuracy:** TON 618's behavior and its approach toward Earth are fictionalized for entertainment.
**Please remember:** You're here to experience a cosmic catastrophe, not admire the NPC character models. ✌️😭

## ✨ Features

- **First-person exploration** — Walk around the environment and explore the town.
- **Third-person perspective** — Experience the world from another camera angle.
- **Dynamic pedestrians** — NPCs wander around and react to approaching danger.
- **Vehicle simulation** — Cars move through the streets and respond to the unfolding event.
- **Enterable buildings** — Explore houses and their interior environments.
- **Day and night atmosphere** — Experience different lighting conditions.
- **TON 618 simulation** — Watch the black hole gradually approach Earth.
- **Astronomical visuals** — Stars, accretion effects, gravitational lensing, and intense illumination.
- **Environmental reactions** — NPCs panic and attempt to escape as danger approaches.
- **Mobile-friendly controls** — Touch controls for supported mobile configurations.
- **Resizable window** — Adapt the simulation to different screen sizes.

## 📦 Installation

### 1. Install Python

Download Python from:

https://www.python.org/downloads/

### 2. Clone the repository

```bash
git clone https://github.com/YOUR_USERNAME/ton-618-punjab-simulation.git
cd ton-618-punjab-simulation
```

### 3. Install dependencies

```bash
pip install pygame
```

### 4. Run the simulation

```bash
python main.py
```

## 🌌 About TON 618

TON 618 is an extremely massive quasar-associated black hole located billions of light-years away.

This project uses TON 618 as the central astronomical event, depicting a fictional scenario in which it appears to approach Earth.

**Important:** The simulation is fictional. TON 618 is not approaching Earth, and the visual effects are not scientifically accurate predictions of an actual astronomical event.
